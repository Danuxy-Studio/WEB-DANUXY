# PRD — DANUXY.COM v2.0

## Official Brand Identity

**Brand:** Danuxy Studio

**Official tagline:** `BUILD • CREATE • GROW`

### Visual identity

Danuxy uses the new `D` + forward/speed mark as its official logo direction.

**Official palette:**
- Sky Blue (Primary): `#4ED1FF`
- Blue (Secondary): `#2EA8FF`
- Light Blue (Accent): `#E6F4FF`
- Dark Navy: primary dark background/supporting color

### Logo rules
- Use the clean/minimal logo variant as the main website logo.
- Use the icon-only variant for favicon, compact navigation, and small UI.
- Do not stretch, distort, rotate, or unnecessarily recolor the logo.
- Avoid excessive glow.
- Keep the logo readable at small sizes.

### Brand copy
`BUILD • CREATE • GROW` is the official brand tagline.

The supporting website statement may be:

> Building things, breaking things, and vibe coding my way through it.

The tagline represents the brand; the supporting statement represents the personality of the website.

### Visual direction
- Dark navy foundation
- Sky blue and blue accents
- Light blue highlights
- Clean, solid, professional shapes
- Subtle gradients only where useful
- Minimal glow
- Strong contrast
- Responsive and lightweight

Avoid purple as a primary brand color, excessive neon/glow, and generic SaaS-style visual clutter.


## 1. Tujuan

`danuxy.com` menjadi website resmi **Danuxy Studio** untuk:

- Memperkenalkan Danuxy Studio.
- Menampilkan project yang pernah dibuat.
- Menjelaskan layanan.
- Mengarahkan pengunjung ke NIXI.
- Menampilkan artikel/tutorial teknologi.
- Menjadi pusat link sosial dan community.
- Menjadi website dengan konten yang cukup kuat untuk diajukan ke Google AdSense.

Website bukan dibuat sebagai website penuh iklan. Konten dan pengalaman pengguna tetap menjadi fokus utama.

## 13. AdSense Readiness

**Jangan memasang iklan pada fase awal.**

Flow:

```text
Build website
      ↓
Deploy danuxy.com
      ↓
Isi Projects
      ↓
Isi About
      ↓
Isi Blog
      ↓
Privacy / Terms / Cookies
      ↓
Test mobile + desktop
      ↓
Google Search indexing
      ↓
Submit danuxy.com ke AdSense
      ↓
Review
      ↓
Jika disetujui → pasang ads
```

Prioritas utama adalah konten original, berguna, navigasi jelas, dan pengalaman pengguna yang baik.

# Prompt untuk Antigravity

Gunakan PRD ini sebagai sumber utama pekerjaan.

> Read and follow `PRD-DANUXY-COM-2.0.md`.
>
> Upgrade the existing `WEB-DANUXY` Express + EJS project into the official Danuxy Studio website at `danuxy.com`.
>
> IMPORTANT:
> - Do not migrate to Next.js.
> - Preserve Express + EJS architecture.
> - Preserve existing dark/light mode and responsive behavior.
> - Use Indonesian for all website content and UI.
> - Do not generate generic AI-looking copy.
> - Do not invent statistics, customers, testimonials, achievements, or claims.
> - Use real Danuxy Studio projects such as NIXI and GTH SMP.
> - Build the website as a real studio/portfolio/content website, not an ad-only landing page.
> - Prioritize original, useful content and SEO.
> - Add Projects, About, Services, Blog, NIXI, Contact, Privacy Policy, Terms, Cookies, sitemap.xml, robots.txt, canonical URLs, Open Graph metadata, JSON-LD, and cookie consent.
> - Keep the UI modern, lightweight, developer-oriented, clean, and responsive.
> - Avoid excessive animations and visual clutter.
> - Ensure every route works.
> - Do not remove existing functionality unless it is replaced by a better implementation.
> - Run type/lint/build checks that are available in the repository after implementation.
>
> Before editing files, inspect the entire repository and existing views/styles/scripts. Then implement the PRD incrementally.
